2.1 Crear, Editar y Ajustar Productos (Boton "Anadir Producto" desbloqueado)
- Archivo: backend/src/routes/pos.routes.ts

* Crear Producto:
  POST /api/v1/pos/products
  Body JSON:
  {
    "nombre": "Leche Entera Colun 1L",
    "codigo_barra": "7801234567890",
    "sku": "COL-LEC-001",
    "precio_compra": 850,
    "precio_venta": 1190,
    "stock_actual": 24,
    "stock_minimo": 6,
    "categoria": "Lacteos",
    "proveedor_id": "uuid-opcional",
    "lote": "LOTE-2026-X",
    "fecha_vencimiento": "2026-11-30",
    "impuesto_adicional_codigo": 0,
    "impuesto_adicional_tasa": 0
  }
  Respuesta: 201 Created (replicado en SQLite y PostgreSQL).

* Editar Producto:
  PUT /api/v1/pos/products/:id
  Body JSON: Acepta actualizacion parcial o total de campos.
  Respuesta: 200 OK con datos actualizados.

* Ajuste Manual de Stock (Conteo Fisico / Auditoria Express):
  PATCH /api/v1/pos/products/:id/stock
  Body JSON:
  {
    "nuevo_stock": 20,
    "motivo": "Conteo fisico turno tarde",
    "usuario_id": "Cajero 1"
  }
  Respuesta: 200 OK con calculo de delta y registro en historial_stock.

2.3 Registro de Mermas (Boton "Registrar Merma" desbloqueado)
- Archivo: backend/src/routes/pos.routes.ts

* Registrar Merma:
  POST /api/v1/pos/mermas
  Body JSON:
  {
    "producto_id": "uuid-del-producto",
    "cantidad": 3,
    "motivo": "vencimiento",
    "observaciones": "Envase danado en gondola 2",
    "usuario_id": "Cajero 1"
  }
  Comportamiento: Descuenta stock de forma atomica en tabla productos, inserta en
  tabla mermas y asienta en historial_stock.
  Respuesta: 201 Created.

* Historial de Mermas:
  GET /api/v1/pos/mermas?tenant_id=...
  Respuesta: 200 OK con listado historico detallado.
