LO DE DOCKER NO ES

Me dijiste que habia que tener Docker abierto. Lo probe con el contenedor arriba
y sano, y falla exactamente igual:

    [ERROR] [InitDB]: Failed during SQLite initialization
      Migrations directory not found: ...\sqlite\migrations

            Continuing in local mode.

Lo que mata el arranque es SQLite, que es la base local y no depende de Docker.

con Docker apagado no es un problema.

De paso queda confirmado algo que iba a poner como advertencia: las migraciones
de PostgreSQL tampoco estan en el paquete. Es la misma causa, no dos problemas.

COMO LO ARREGLARIA

1. COPIAR LOS .sql A dist DENTRO DE build:desktop. Asi viajan bajo
   dist/backend/**/*, que ya esta en files, tu regla de no mandar codigo fuente
   sigue siendo cierta, y la prueba de empaquetado no se rompe. Agregar
   backend/src a files tambien funcionaria, pero mandaria el codigo al equipo del
   local, que es justo lo que decidiste evitar.

   Y que el migrador resuelva primero __dirname y despues la ruta del proyecto.
   Hoy el camino principal es el que solo existe donde el producto nunca corre.

2. QUE instalacion.json SE ESCRIBA DESPUES. Primero inicializar la base y
   comprobar que quedo, y recien entonces marcar la instalacion. Como esta ahora,
   el archivo se escribe apenas se teclea la cuenta: el siguiente arranque ya no
   muestra la ventana del primer inicio, va directo a levantar el backend, falla
   igual y se cierra. Un fallo del primer arranque deja la instalacion sin forma
   de reintentar, y borrar la carpeta de datos a mano no es algo que un local
   sepa hacer.

3. QUE EL FALLO SE VEA. Hoy la ventana se cierra en silencio y hay que correr el
   .exe desde una terminal para enterarse de algo. Un cuadro de dialogo con el
   motivo bastaria.

4. QUE NO QUEDEN PROCESOS VIVOS. Despues de los intentos fallidos encontre cuatro
   GesTock.exe colgados. Por eso mi primer relanzamiento no hizo nada: choco con
   el bloqueo de instancia unica y salio sin mostrar el error. Si el arranque
   falla, el proceso deberia terminar.
