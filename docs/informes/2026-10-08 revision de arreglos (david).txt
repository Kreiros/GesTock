1. ENABLE_MOCK_OCR esta en la documentacion pero el codigo no la lee

La agregaste al .env.example y a la guia:

    ENABLE_MOCK_OCR=false   # Si es false, no alucina compras ante fallos

La busque en todo backend/src y no aparece. Lo que decide si el simulador
participa es esto, en ocr-dispatcher.service.ts:

    const hasApiKey = Boolean(process.env.GEMINI_API_KEY);
    const isProduction = process.env.NODE_ENV === 'production';
    if ((hasApiKey || isProduction) && !input.simulateFailure) { ... }

Depende de si hay API key o de si estamos en produccion, no de la variable.

Entonces si alguien pone ENABLE_MOCK_OCR=false esperando cerrar el simulador no
pasa nada, y si lo pone en true para probar, tampoco. Y en desarrollo sin
GEMINI_API_KEY el simulador sigue inventando facturas completas que la pantalla
muestra como reales.

Se arregla con una linea leyendo la variable en esa condicion. O si prefieres
que el gate sea la API key, sacala de los documentos.

Aparte el 422 lo detectas comparando el texto del mensaje:

    const statusCode = errorMsg.includes('No fue posible digitalizar') ? 422 : 500;

Funciona, pero si alguien cambia ese texto el status se cae a 500 y nadie se
entera. Un codigo de error en el objeto seria mas firme.
